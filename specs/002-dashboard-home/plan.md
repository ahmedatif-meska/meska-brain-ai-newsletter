# Plan: Dashboard Home (`/home`)

**Branch**: `004-landing-redesign` (active) | **Date**: 2026-05-21 | **Spec**: [./spec.md](./spec.md)

**Input**: Feature specification at `specs/002-dashboard-home/spec.md`

## Summary

Phase 2 of the Meska Brain plan: build a signed-in landing page at `/home` showing a
personalized greeting, a Profile Progress card (0% / ~33% / ~66% / 100%), a tagline,
and a persistent top navigation (wordmark + Home + Profile + Sign Out). White background
with neon-blue accents — no dark-theme leakage. The auth session is enforced
server-side; unauthenticated requests redirect to `/signin`.

This is the first dashboard surface. Sign-in already redirects to `/home`
(`app/(auth)/_actions/signin.ts`), so the route currently 404s. Profile completion is
derived from a single read-only contract whose source is whichever Phase 3 forms have
been persisted; before Phase 3 lands, the contract returns 0% for every user.
